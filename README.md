# VendorVerse

A full-stack MERN marketplace platform that enables local businesses to create digital storefronts, manage products and services, and connect with customers through an intuitive web interface.

## Features

* Vendor profile and storefront management
* Product and service management
* Business dashboard
* CRUD operations for products and services
* Responsive user interface
* RESTful API integration
* MongoDB database integration
* Full-stack deployment on Render

## Tech Stack

### Frontend

* React.js
* Tailwind CSS

### Backend

* Node.js
* Express.js

### Database

* MongoDB

## Project Structure

```bash
client/
server/
```

## Installation

### Clone Repository

```bash
git clone <your-repository-url>
cd VendorVerse
```

### Install Dependencies

Frontend:

```bash
cd client
npm install
```

Backend:

```bash
cd server
npm install
```

### Run Application

Backend:

```bash
npm start
```

Frontend:

```bash
npm run dev
```
